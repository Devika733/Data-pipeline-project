# Data-pipeline-project

## About the Project
This project implements an end-to-end data pipeline designed to ingest, process, and store data efficiently. It simulates a real-world production environment where data reliability and scalability are crucial.

## Tech Stack
*   Database: SQL, Oracle PL/SQL (Stored Procedures, Functions, Packages, Triggers)
*   Pipeline Logic: Python
*   Version Control: Git & GitHub

## Project Workflow
1.  Data Ingestion: Extracting raw data from source systems.
2.  Data Transformation: Cleaning and structuring the data using PL/SQL for robust error handling and business logic implementation.
3.  Data Loading: Orchestrating the flow and loading the processed data into target tables for analytics and reporting.
